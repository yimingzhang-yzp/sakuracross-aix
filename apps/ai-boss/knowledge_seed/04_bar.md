# バー業務マニュアル

> 雛形です。【店舗確認】は店長が実際のレシピ・価格・POS 手順に置き換えてください。

## バー担当の心得

- 衛生第一。手洗いは出勤時・トイレ後・現金を触った後に必ず行う
- グラス・ツール・カウンターは常に拭き上げ、氷は素手で触らない(必ずアイススコップまたはトング)
- 提供前に「誰に何を出すか」を必ず確認する。間違えて出したドリンクは回収せず、責任者に報告して伝票を修正する
- 酔いが進んでいるお客様への提供は断る勇気を持つ(詳細は「トラブル対応マニュアル」)

## グラスの種類と用途

| グラス | 用途 |
|---|---|
| タンブラー(ロング) | ハイボール、ジントニック、カシスオレンジなどのロングドリンク、ソフトドリンク |
| ロックグラス | ウイスキー・テキーラ等のロック、ネグローニなど |
| ショットグラス | テキーラショット、ショットドリンク(30ml) |
| シャンパングラス(フルート) | シャンパン、スパークリング |
| ワイングラス | 赤・白ワイン |
| プラスチックカップ | 【店舗確認】フロアが混雑する時間帯(例 24:00 以降)はガラス割れ防止のためプラカップに切り替える |

## 標準レシピ(【店舗確認】店の規定量に置き換え)

計量は必ずメジャーカップ(ジガー)で行う。目分量は原価ブレと提供量の不公平につながる。

- ハイボール: ウイスキー 30ml + ソーダ 適量、レモンピール。氷はグラス満杯
- ジントニック: ジン 30ml + トニックウォーター 適量、ライム 1 カット
- モスコミュール: ウォッカ 30ml + ジンジャーエール 適量、ライム
- カシスオレンジ: カシスリキュール 30ml + オレンジジュース 適量
- テキーラショット: テキーラ 30ml、ライム・塩を添える
- ウイスキーロック: ウイスキー 45ml、ロックアイス
- レッドブルウォッカ: ウォッカ 30ml + レッドブル 1 缶(【店舗確認】)
- ノンアルコール: ソフトドリンク各種、モクテル【店舗確認】

## ドリンクチケットの処理

1. お客様からチケットを受け取り、当日分か(日付・色)を確認する
2. チケット対象メニュー【店舗確認】から 1 杯を提供する。対象外のドリンクを希望された場合は差額精算ができるか【店舗確認】ルールに従う
3. 使用済みチケットは指定の回収箱に入れる。裏面にペンでチェックを入れて再利用を防ぐ
4. 期限切れ・破損で判別できないチケットは受け付けず、責任者に判断を委ねる
5. 営業終了後、回収枚数と POS のチケット売上件数を照合する

## POS 操作の基本手順(【店舗確認】機種に応じて更新)

1. ログイン: 自分の担当者コードでログインする(他人のコードは使わない)
2. 注文入力: 商品ボタン → 数量 → 「注文確定」。テーブル会計は伝票番号を選択してから入力
3. 会計: 「会計」→ 支払方法(現金 / カード / QR)→ 金額確認 → 完了。レシートは必ず渡す
4. 取消: 確定後の取消は**責任者コード**が必要。自分で取り消さず責任者を呼ぶ
5. ドリンクチケット: 「チケット」ボタンで 0 円計上する(売上件数を残すため、入力を省略しない)
6. レジ締め: 営業終了後、責任者と 2 名で現金を数え、POS のレポートと照合する

## 提供時の注意

- 提供前に必ず「何名のうち誰のドリンクか」を確認し、置き間違えを防ぐ
- 席を離れたお客様のドリンクは、戻るまでバー側で預かる(睡眠薬混入など事件防止のため。【店舗確認】預かり方法)
- 一度に大量のショットを求められた場合(例 5 杯以上)は責任者に確認する
- 明らかに酔っているお客様には「本日はソフトドリンクのご用意になります」とお伝えする。断り方に迷ったら責任者を呼ぶ

## 在庫・補充

- ボトルは残量が 1/4 を切ったら次を出しておく。開栓日は【店舗確認】ラベルに記入
- 氷・ガーニッシュ(レモン・ライム)は 23:00 と 01:00 に補充【店舗確認】
- 割り物(ソーダ・トニック・ジュース)の在庫が少なくなったら、閉店前に責任者へ報告する

## 衛生・清掃

- 使用済みグラスはすぐに下げ、洗浄機へ。割れたグラスは素手で拾わず、ほうきと専用容器で処理
- カウンター下のこぼれはその都度拭く(滑って転倒する事故が多い)
- 営業終了後: シンク清掃、ドリンクガンのノズル洗浄、ゴミ出し、冷蔵庫の温度確認【店舗確認】
