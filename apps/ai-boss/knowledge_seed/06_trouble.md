# トラブル対応マニュアル

> 雛形です。【店舗確認】は店長が実際の連絡フロー・連絡先に置き換えてください。
> 生命に関わる緊急時(救急・火災・警察)は「緊急連絡マニュアル」の固定手順が最優先です。

## トラブル対応の共通原則

1. **自分の安全を最優先**。無理に制止・追跡しない
2. **一人で対応しない**。すぐに責任者(店長・副店長)とセキュリティに合図する(【店舗確認】合図・インカム・呼び出し方法)
3. **お客様と口論しない**。「申し訳ございません」「責任者を呼びます」で引き継ぐ
4. **記録する**。時刻・場所・関係者の特徴・経緯を、落ち着いてからメモし責任者へ報告する
5. **写真・動画を撮らない、SNS に書かない**

## 泥酔したお客様

見分け方: ふらついている、ろれつが回らない、同じ話を繰り返す、目の焦点が合わない、他のお客様に絡む。

1. 酒類の提供を止める。「本日はお水をお持ちします」と伝え、水を出す
2. 責任者に報告する。責任者がお客様の同行者を確認し、帰宅の手配(タクシー・同行者の付き添い)を進める
3. 店内で休ませる場合は【店舗確認】指定の場所で、必ずスタッフが見守る。一人で放置しない
4. 嘔吐しそうな場合はトイレへ誘導し、袋・タオルを用意する。嘔吐物の処理は手袋・専用キット【店舗確認】で
5. 意識がもうろうとしている、呼びかけに反応しない、呼吸が浅い → **救急対応**(緊急連絡マニュアル)。迷わず 119
6. 一人で帰らせない。タクシー乗車まで見送り、行き先を運転手に伝える(【店舗確認】タクシー会社)

## 喧嘩・暴力行為

1. 自分は間に入らない。大声で「やめてください」と制止しつつ、セキュリティと責任者を呼ぶ
2. 周囲のお客様を距離のある場所へ誘導する。グラス・ボトルなど武器になるものを下げる
3. セキュリティが当事者を分離する。分離後は別々の出口から退店してもらう
4. けが人がいれば救急対応。刃物・暴力が収まらない場合は **110 通報**(責任者判断。緊急連絡マニュアル)
5. 当事者の特徴(服装・人数・名前がわかれば)と経緯を記録し、責任者が【店舗確認】出入り禁止リストへの登録を判断する

## 盗難・紛失

1. お客様から「財布(スマホ)が無い」と申し出があったら、まず落ち着いていただき、最後に使った場所・時刻を聞く
2. クロークの忘れ物・落とし物を確認する(クローク・館内マニュアル)。テーブル・ソファの隙間・トイレも確認
3. 見つからない場合は責任者に引き継ぐ。責任者が防犯カメラ【店舗確認】の確認可否を判断する
4. 盗難の疑いが強く、お客様が届け出を希望する場合は、責任者が警察への連絡を案内する。スタッフが「盗まれた」と断定して他のお客様を疑う言動はしない
5. 後日連絡先を控える場合は【店舗確認】紛失物受付票に記入し、責任者が保管する

## 体調不良のお客様

1. 声をかけ、意識・呼吸を確認する。座れる場所か横になれる場所【店舗確認】へ移動する
2. 責任者を呼ぶ。同行者がいれば呼ぶ
3. 以下のいずれかがあれば**迷わず 119**: 呼びかけに反応しない、呼吸が浅い・不規則、けいれん、激しい頭痛や胸の痛みを訴える、頭を打っている
4. 飲食物・薬は与えない。嘔吐がある場合は横向きにして気道を確保する
5. 回復しても一人で帰さない。同行者またはタクシーで帰宅させる

## ハラスメント・迷惑行為

- お客様同士のしつこいナンパ・身体接触: 被害を受けているお客様に「大丈夫ですか」と声をかけ、責任者・セキュリティに伝える。加害側への注意はセキュリティ・責任者が行う
- スタッフへのセクハラ・暴言: 我慢せず、その場を離れて責任者に報告する。スタッフを守るのは店の責任
- 無断撮影: 「店内での撮影はご遠慮いただいています」と伝える。応じなければ責任者へ

## 警察対応の一次手順(責任者が到着するまで)

- 警察官が来店したら、丁寧に応対し、すぐに責任者を呼ぶ。スタッフは店の状況や個人情報について勝手に説明しない
- 提示を求められた書類(営業許可証等)の場所は【店舗確認】。責任者が対応する
- お客様が警察を呼びたいと言った場合は止めない。責任者に伝える

## 報告

- すべてのトラブルは、その日のうちに責任者へ口頭報告し、【店舗確認】日報(トラブル報告欄)に記録する
- 「たいしたことじゃない」と自己判断で報告を省かない。小さな報告が大きな事故を防ぐ
