# エントランス業務マニュアル

> 雛形です。【店舗確認】は店長が実際の料金・ルールに置き換えてください。

## エントランス担当の役割

エントランス(ドア)はお客様が最初に接する場所であり、同時に店の安全を守る最初の関門です。担当は以下を同時に行います。

1. 挨拶とお出迎え
2. 年齢確認(ID チェック)— 詳細は「IDチェック・年齢確認マニュアル」を必ず参照
3. ドアチャージ(入場料)の収受
4. 入場リストバンド・スタンプの装着
5. ドリンクチケットの配布
6. 持ち込み・危険物・服装の確認
7. 入場者数のカウント(定員管理)

## ドアチャージ料金体系

【店舗確認】以下は例です。実際の料金表に置き換えてください。

| 区分 | 料金 | 備考 |
|---|---|---|
| 一般(男性) | 【店舗確認】3,000 円 | ドリンクチケット 1 枚付き |
| 一般(女性) | 【店舗確認】2,000 円 | ドリンクチケット 1 枚付き |
| 学生(要学生証、20 歳以上) | 【店舗確認】 | |
| ゲストリスト掲載者 | 【店舗確認】無料または割引 | 指定時刻(例 24:00)までの入場に限る |
| イベント開催日 | イベントごとに責任者から通知 | 通常料金は適用しない |

- 料金は入場時に前払い。現金・クレジットカード・QR 決済(【店舗確認】対応ブランド)
- 料金表に無い割引を求められたら、自分で判断せず責任者に確認する
- お釣り・レシートは必ず渡す。レジの締めは責任者と 2 名で行う

## ゲストリスト運用

- ゲストリストは責任者(またはプロモーター)が【店舗確認】指定のツールで当日 20:00 までに確定する
- 入場時にお名前を伺い、リストと照合する。本人確認のため ID は通常どおり確認する
- リストに名前が無い場合: 「リストにお名前が見当たりません」と伝え、通常料金をご案内する。もめる場合は責任者を呼ぶ
- ゲストリストの締め時刻(例 24:00)を過ぎたら、リスト掲載者も通常料金

## ドリンクチケット

- 入場料に含まれるドリンクチケットは入場時に 1 人 1 枚渡す(【店舗確認】枚数)
- チケットは当日限り有効。翌日以降・他人への譲渡・現金との交換はできない
- チケットの交換対象ドリンクはバーの「チケット対象メニュー」のみ(【店舗確認】。プレミアム・ボトルは対象外)
- 紛失した場合の再発行はしない。お客様から強く求められたら責任者に判断を委ねる
- 使用済みチケットはバーで回収し、営業終了後に枚数を集計する

## 再入場ルール

- 再入場は【店舗確認】可 / 不可
- 可の場合: 退店時にリストバンドまたは再入場スタンプを確認し、当日中(閉店まで)であれば無料で再入場できる
- リストバンドが外れている・スタンプが消えている場合は再入場不可(改めて入場料が必要)。例外は責任者判断
- 再入場時も酔い具合・所持品の確認は初回と同じ基準で行う

## 入場をお断りするケース

以下に該当する場合は入場をお断りします。断る際は理由を簡潔に伝え、争わない。応じない場合はセキュリティ・責任者を呼ぶ。

- 年齢が確認できない、または 20 歳未満(詳細は ID チェックマニュアル)
- 明らかに酩酊している(ふらつく、ろれつが回らない、嘔吐しそう)
- 危険物・持ち込み飲食物を所持している
- 服装が店のドレスコード【店舗確認】に反する
- 過去に出入り禁止となっている(【店舗確認】管理リストの確認方法)
- 定員に達している(責任者の指示による入場制限)

## 定員管理

- 入場者数は【店舗確認】カウンター/アプリで常時カウントし、退店者数を差し引く
- 定員は【店舗確認】名。定員に近づいたら責任者に報告し、入場待ちの列を作る
- 定員超過は消防法違反となるため、責任者の許可なく定員を超える入場はさせない
