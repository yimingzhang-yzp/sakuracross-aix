# 緊急連絡マニュアル

> 雛形です。【店舗確認】は店長が実際の避難経路・連絡先に置き換えてください。
> 「救急」「火事」「警察」を含むメッセージには、このマニュアルとは別に固定の緊急手順が即時に返されます(管理画面「設定」で編集)。

## 責任者連絡フロー

緊急時は「その場の責任者 → 店長 → オーナー」の順に連絡します。連絡がつかない場合は次の人へ進みます。

| 順位 | 役職 | 連絡先 |
|---|---|---|
| 1 | 当日責任者(店長または副店長) | 【店舗確認】店内インカム / 携帯 000-0000-0000 |
| 2 | 店長 | 【店舗確認】000-0000-0000 |
| 3 | オーナー | 【店舗確認】000-0000-0000 |
| — | 警備会社 | 【店舗確認】000-0000-0000 |
| — | ビル管理会社(設備・エレベーター) | 【店舗確認】000-0000-0000 |

- 119(救急・火災)・110(警察)への通報は、生命の危険があるときは**責任者の到着を待たず**スタッフが行ってよい
- 通報時に伝えること: 「六本木の CROSS ROPPONGI(住所【店舗確認】、ビル名・階)、状況(人が倒れた / 火が出た)、けが人の人数、自分の名前」

## 救急(人が倒れた・意識がない)

1. 周囲の安全を確認し、大声で人を呼ぶ。責任者に連絡
2. 肩を叩いて呼びかけ、反応と呼吸を確認する
3. 反応がない・呼吸がない → 119 通報。AED【店舗確認】設置場所から持ってくる人を指名する
4. 胸骨圧迫を開始(胸の真ん中を、1 分間に 100〜120 回のテンポで、強く・速く・絶え間なく)。AED が届いたら音声ガイドに従う
5. 反応はあるが具合が悪い → 楽な姿勢で休ませ、嘔吐に備えて横向きに。飲食物は与えない
6. 救急隊到着後、経過(いつ倒れたか、飲酒量、既往症がわかれば)を伝える

## 火災

1. 「火事だ!」と大声で知らせ、火災報知器を押す
2. 初期消火: 消火器【店舗確認】設置場所。炎が天井に届いていたら消火をやめて避難する
3. 119 通報
4. お客様の避難誘導(下記「避難経路」)。エレベーターは使わない
5. 煙が出ている場合は姿勢を低くし、ハンカチで口を覆う
6. 避難後、責任者が点呼を取る。逃げ遅れがいる場合は消防隊に伝える。自分で戻らない

## 地震

1. 揺れている間: 頭を守り、棚・ボトル・照明から離れる。お客様にも「頭を守ってしゃがんでください」と声をかける
2. 揺れが収まったら: 火元(ガス・ろうそく・スパークラー)を確認。責任者の指示を待つ
3. 避難が必要な場合は責任者の指示で避難経路から誘導する。ガラスの破片に注意
4. 停電時は非常灯を確認し、スマートフォンのライトで足元を照らす。会計は責任者の判断
5. エレベーターに閉じ込められた人がいたら、ビル管理会社と 119 に連絡

## 避難経路

【店舗確認】以下は例です。実際のフロア図に置き換え、全スタッフが実際に歩いて確認してください。

- 主出口: エントランス → 階段 → 1 階 → ビル正面出口
- 非常口 A: フロア奥(DJ ブース右)→ 非常階段 → ビル裏口
- 非常口 B: VIP エリア横 → 非常階段
- 集合場所: 【店舗確認】ビル前の交差点を渡った公園
- 非常口・避難経路の前に荷物・機材を置かない。塞がっていたらすぐに移動し、責任者に報告する

## 避難誘導の基本

- 「落ち着いてこちらへ」と大きな声で、出口方向を腕で示す
- 走らせない、押させない。階段では手すり側を歩かせる
- 荷物(クロークの預かり品)を取りに戻らせない。命が優先
- 体の不自由な方・酔って歩けない方は 2 名で支えて誘導する
- お客様を全員出してから、スタッフが最後に出る。責任者が最終確認する

## 警察を呼ぶケース

- 刃物・凶器を持った人がいる、暴力が収まらない、けが人が出た
- 盗難・傷害の被害届をお客様が希望する
- 不審物・不審者
- 通報の判断は責任者が行うのが原則。ただし身の危険が迫っている場合はスタッフが 110 通報してよい

## 緊急時の記録

- 落ち着いてから、時刻・場所・状況・対応した人・通報の有無を責任者に報告し、【店舗確認】事故報告書に記録する
- 記録は再発防止のために使う。責任追及のためではないので正確に書く
